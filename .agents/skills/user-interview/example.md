# Worked example

Illustrative editorial example, not a model benchmark or measured customer outcome.

## Input

I interviewed three freelance bookkeepers. Two manually check CSVs; one has automated imports. Help me decide what to ask next before building duplicate detection.

## Output

Current evidence: two people described manual CSV checking; one already uses automation. This suggests a possible segment, not validated demand.

Ask the two manual users: “Walk me through the last reconciliation. Which entries took extra checking? What did you compare? What happened if you missed one?” Ask the automated user what still needs manual review.

Next decision: seek a real recent example and observe the current check before committing to a detection workflow. Do not infer willingness to pay from these three notes.
