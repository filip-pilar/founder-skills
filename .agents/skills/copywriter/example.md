# Worked example

Illustrative editorial example, not a model benchmark or measured customer outcome.

## Input

Rewrite this landing-page headline for solo bookkeepers: “The all-in-one AI-powered financial productivity platform.” We import bank CSVs and flag possible duplicate transactions. No bank integrations yet.

## Output

Headline: Find possible duplicate transactions before closing the books.
Subheading: Upload a bank CSV and review flagged entries in one place. Built for solo bookkeepers.
CTA: Check a CSV

Why: Names the actual job and input. “Possible” preserves the distinction between a flag and a confirmed duplicate. No unsupported accuracy or integration claim.
