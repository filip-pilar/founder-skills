# Worked example

Illustrative editorial example, not a model benchmark or measured customer outcome.

## Input

Should we add integrations or improve CSV review? Two trial users struggled to understand duplicate flags. One asked about bank sync. We have one developer.

## Output

Recommendation: improve CSV review first. Two users struggling with the central result is stronger evidence of a current bottleneck than one request for another input method. Bank sync would feed more data into the same confusing review.

Make a small change that explains each flag, then observe the same two users on new examples. Reconsider integrations if import friction prevents otherwise successful use. This prioritizes observed comprehension trouble; it does not prove that integrations lack future value.
