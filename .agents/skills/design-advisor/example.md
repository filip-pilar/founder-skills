# Worked example

Fictional example.

## Input

Our CSV upload screen shows Import, Start, Sync and Process buttons together. Users only need to upload one file and review flagged entries. Suggest a clearer layout.

## Output

Based on the described controls, the main issue is four overlapping actions before the user understands the sequence.

Proposed flow: “Upload a bank CSV” with one file picker; after validation, “Review possible duplicates”; then a review table with clear dismiss/confirm actions. Keep progress and import errors next to the file. An unsupported file should explain the accepted format and preserve the chosen file where possible.

Visual hierarchy and contrast need a screenshot or page inspection; they cannot be judged from the button names alone.
