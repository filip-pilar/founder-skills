# Worked example

Illustrative editorial example, not a model benchmark or measured customer outcome.

## Input

We changed our pricing page and got 3 purchases from 80 visits, versus 2 from 70 the previous week. Should we roll it out?

## Output

Recommendation: treat this as inconclusive. The observed rates are 3.75% (3/80) and about 2.86% (2/70), but five purchases across different weeks do not establish a pricing-page effect. Traffic mix or chance could explain the difference.

Keep the change only if there is an independent usability reason and it is easy to reverse. To estimate its effect, use comparable allocation, a defined conversion event and an observation window based on available traffic. If traffic is too low, inspect real purchase attempts to learn where customers hesitate.
